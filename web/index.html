A note on this playground
This uses OpenVerse, an independent implementation of a subset of Verse. It is not affiliated with Epic Games. Programs start at Main():void. Use Print("hello") for output and Args for text input. Mouse, graphics, and live stdin are not available here.
The step limit keeps loops bounded. Output is shown when execution finishes, including Verse’s rollback rules. This playground accepts one source file; filesystem imports are unavailable.
